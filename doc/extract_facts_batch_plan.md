# Goal Description
The agent currently performs sequential LLM fact extraction using `extract_and_add_facts` instead of the faster `extract_and_add_facts_batch`. This causes large bottlenecks and poor GPU utilization (accounting for ~80% of trace time). 

**Why is it happening?**
The AI is receiving mixed signals. The system prompt in `evidence_programming.py` explicitly tells the agent to use `extract_and_add_facts(llm, pmid, state)` in several places (e.g., in the "CRITICAL: Grounded Evidence Only" section and the fallback instructions), and only mentions the batch version as an option for "multiple papers". LLMs often default to simpler `for pmid in pmids:` loops and call the single-item signature since it's repeatedly emphasized.

**The Fix:**
Force the agent to *only* use batched extraction. We will rename the single-paper function to be private `_extract_and_add_facts_single`, rename `extract_and_add_facts_batch` to `extract_and_add_facts`, and update the system prompts to only reference the batched version.

## Proposed Changes

### 1. `src/pkevolve/verification/evidence_api.py`
- Rename `extract_and_add_facts` to `_extract_and_add_facts_single`.
- Rename `extract_and_add_facts_batch` to `extract_and_add_facts` (making it the default and only internal extraction method).
- Update the new `extract_and_add_facts` (formerly batch) to call `_extract_and_add_facts_single` internally.
- Update `function_docs()` to remove `extract_and_add_facts_batch` from `_api_funcs` list (keep `extract_and_add_facts`).
- Update the docstrings to clarify that `extract_and_add_facts` now accepts a list of identifiers (`pmids: list[str]`).
- In `schema_docs()`, modify the instruction: *"If extract_and_add_facts returns 0 for a specific pmid..."* since it now returns a dictionary of `pmid -> count`.

### 2. `src/pkevolve/verification/evidence_programming.py`
- Modify the `SYSTEM_PROMPT` to remove all explicit references to single-paper sequential extraction.
- Change Step 5: `5. Extract facts from papers. Use extract_and_add_facts(llm, pmids, state, max_workers=8) to process all newly retrieved papers in parallel. Do NOT write fact dicts manually.`
- Update the "CRITICAL: Grounded Evidence Only" instructions: 
  - Change to `- Use extract_and_add_facts(llm, pmids, state) to extract facts in parallel.`
  - Update the fallback fallback code block to iterate properly if a certain paper returns `0` facts.
